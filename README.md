## ✨ Sekilas

Tiga panduan, satu tujuan: **memudahkan Anda mengoperasikan Fingerspot.io** — dari aktivasi paket hingga registrasi karyawan. Semua berkas berdiri sendiri: font dan gambar tertanam langsung, tanpa server, tanpa build, tanpa internet.

> 🎯 **Cukup klik dua kali berkas `.html` — panduan langsung terbuka di peramban.**
