# Panduan Fingerspot.io

Kumpulan panduan pengguna Fingerspot.io dalam satu berkas HTML — mandiri (tanpa koneksi internet, font dan gambar tertanam langsung) dan siap dicetak/simpan sebagai PDF.

## Isi

| Berkas | Tentang |
| --- | --- |
| [cara_mudah_aktivasi_paket_umkm_fingerspot_fix (1).html](<cara_mudah_aktivasi_paket_umkm_fingerspot_fix (1).html>) | Panduan aktivasi FREE Paket UMKM (file utama) — berisi sidebar daftar isi geser (hamburger), langkah 1–15 berurutan, siap cetak. |
| [aktivasi_bundling_v2 (2).html](<aktivasi_bundling_v2 (2).html>) | Panduan aktivasi perangkat absensi dengan Paket Bundling — pilihan metode voucher bundling atau kuota perangkat. |
| [panduan_tambah_registrasi_karyawan_revisi_final_v7 (1).html](<panduan_tambah_registrasi_karyawan_revisi_final_v7 (1).html>) | Panduan tambah / registrasi karyawan — manual atau import Excel, dan hubung ke perangkat absensi atau tanpa perangkat. |

## Cara membuka

Cukup buka salah satu berkas `.html` dengan peramban (double-click). Tidak ada latar server, dependensi, maupun proses build — semua berjalan offline.

Untuk mencetak atau menyimpan sebagai PDF, klik tombol **Cetak / Simpan PDF** di kanan atas halaman (format A4, langkah-langkah tidak terpotong antar halaman).
